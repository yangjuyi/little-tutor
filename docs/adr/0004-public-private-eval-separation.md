# ADR-004：公开与私有 Eval 分离

状态：已采纳
日期：2026-10-06

## Context

LLM 评测集如果全部公开，容易围绕固定样本调 Prompt，产生过拟合。
私有题又不能直接进入公开仓库，因为包含本地题料和潜在版权内容。

同时，Prompt 修改后旧 Eval 结果不能继续代表当前版本。

## Decision

- 公开集：9 道种子题 × 5 种作答状态 = 45 条，可进入仓库；
- 私有集：本地真实/训练题，共 180 条，只保存在本机；
- Eval Harness 记录程序判分、归因非空、证据来源、证据不足和过度归因；
- 报告记录 Grader Prompt 指纹；
- 缺少私有题料时测试显式 skip，不把缺少数据伪装成通过；
- 公开与私有结果都只代表当前评测集，不代表教学效果。

当前 Eval 结果、Prompt 指纹和指标解释只由 `evals/RESULTS.md` 与
`CAPABILITY_STATUS.md` 维护；ADR 只记录公开/私有分离的决策。

## Consequences

优点：

- 公开仓库可复现评测框架，不泄露私有题；
- Prompt 版本变化有明确追踪；
- 能区分离线契约验证与真实教学质量。

代价：

- 私有 Eval 不能由外部完全复现；
- 需要在文档中明确样本来源、数量和边界；
- `100%` 指标容易被误读，必须持续解释其含义。
