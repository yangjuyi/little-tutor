# ADR-005：暂缓 RAG 与多 Agent 教学子图

状态：已采纳
日期：2026-10-06

## Context

当前项目只覆盖一元二次方程有限题型，主要缺口是：

- 显式子技能和误解映射；
- 从难度调整升级为教学策略干预；
- 前后测、延迟测和迁移题的外环验证；
- 真实老师可用性。

当前没有足够证据表明外部知识检索或教学多 Agent 是主要瓶颈。

## Decision

先完成诊断和教学干预闭环，再按触发条件引入：

### RAG 触发条件

- 需要教材、课标、题解、老师话术或错因解释库等外部知识；
- 当前结构化规则和 LLM 归因不足；
- 已有评测集可以测引用准确率和幻觉率。

### 多 Agent 触发条件

- 单流程出现明确瓶颈；
- 子任务可分解，并有独立上下文、工具或指标；
- 接口和评测清楚；
- 能做消融证明多 Agent 优于单流程。

## Consequences

优点：

- 避免把 RAG、多 Agent 当作项目成熟度标签；
- 优先验证真正影响教学的诊断、干预和反馈闭环；
- 减少 token、状态同步和调试成本。

代价：

- 短期技术关键词数量较少；
- 需要更清楚地解释“为什么现在不做”；
- 如果未来引入，必须补新的 ADR、评测和迁移方案。
