# ADR-001：使用 LangGraph HITL 工作流

状态：已采纳
日期：2026-10-06

## Context

little-tutor 不是一次性问答，而是包含组卷、老师预审、连续作答、程序判分、
LLM 归因建议、老师确认和画像写回的多阶段流程。

教学场景需要：

- 关键节点暂停并等待老师输入；
- 进程重启后恢复同一会话；
- 对非法审批和未知状态做受控处理；
- 避免恢复时重复执行副作用；
- 保留确定的程序路由，而不是让模型自主决定下一步。

## Decision

使用 LangGraph StateGraph 实现会话级工作流：

- H1：老师预审题目是否可以进入练习；
- H3：老师确认结果、错因和画像更新是否可以生效；
- `interrupt()` 暂停，`Command(resume)` 恢复；
- 条件路由和失败分流由程序控制；
- LangChain 只用于模型适配等外围能力，不是工作流控制核心。

## Consequences

优点：

- 人工审批点、状态转换和恢复语义显式可测；
- 程序事实、LLM 建议和老师决策的边界更清楚；
- 可以将流程作为 workflow 讲解，而不是把它包装成自主 Agent。

代价：

- 状态和持久化设计复杂度上升；
- 必须补 checkpoint、幂等、租约和恢复测试；
- 不能把所有节点简单当作“Agent”，需要区分控制权和执行单元。
